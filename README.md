# 🏪 نظام طراز المتكامل — v1.3.0

منصة تجارة إلكترونية متكاملة بنظام ERP مبيعات ومخزون، مبنية بمعايير إنتاجية
مع تحصين أمني مُختبَر آلياً (**113 اختباراً**) وجاهزية إطلاق تجاري (امتثال ZATCA +
بوابة دفع + استعادة كلمة المرور + توثيق API).

## 📋 نظرة عامة

| المكوّن | التقنية | المنفذ | الوصف |
|---------|---------|--------|-------|
| **Backend** | Django 5.2 + DRF | 8000 | REST API + Token auth (منتهية الصلاحية) + PostgreSQL/SQLite |
| **Marketplace** | React 19 + Vite 7 | 5173 | متجر إلكتروني للعملاء (RTL عربي كامل) |
| **Desktop** | React 19 + Vite 7 | 3000 | لوحة إدارة المبيعات ونقطة البيع POS |

## 🛡️ التحصين الأمني (جديد في v1.0.2)

أغلق النظام الثغرات الحرجة التالية مع اختبارات آلية تثبت الإغلاق:

| الثغرة المغلقة | الإصلاح |
|----------------|---------|
| تصعيد صلاحيات العميل عبر `update_me` | `ProfileUpdateSerializer` فقط — حقول الدور/الصلاحيات للقراءة فقط في كل مسارات القراءة، وتعيينها للمشرف حصراً |
| تجاوز الدفع والخصومات في إنشاء الطلبات | قناة `pos` والخصم لموظفي النظام فقط + سقف خصم 50% + دفعات المتجر لا تكتمل عند الإنشاء مهما كانت الطريقة |
| تجاوز المخزون بتكرار المنتج في عدة أسطر | تجميع الكميات لكل منتج والتحقق من الإجمالي داخل معاملة ذرّية |
| تسريب التكلفة/هامش الربح/المورد/الكميات للعملاء | مسلسل عام `PublicProductSerializer` للواجهة العامة والمسلسل الكامل للموظفين فقط |
| العميل يغيّر حالة طلبه بنفسه | انتقالات الحالة (تأكيد/شحن/تسليم) لموظفي النظام فقط |
| رموز مصادقة دائمة العمر | رموز تنتهي بعد 30 يوماً (قابلة للضبط) + إبطال كامل عند تغيير كلمة المرور |
| لا حد لمحاولات الدخول | تحديد معدل مشدد 10/دقيقة لمسارات الدخول والتسجيل |
| أسرار تطوير مضمّنة في الحزمة | `.env` محذوف من الحزمة + حرّاس إنتاج يرفضون الإقلاع بمفتاح معروف أو `ALLOWED_HOSTS=*` |
| حسابات تجريبية بكلمات مرور ثابتة في الإنتاج | `seed_data` يرفض العمل عند DEBUG=False إلا بعلم `--force-demo` (وكلمات المرور حينها عشوائية) |

| 🟠 هيرو الرئيسية | توزيع تحريري: قوس معماري بإطار ذهبي + شريحة سعر عائمة حقيقية + عنوان El Messiri كبير + CTA واضح |

| 🟠 الثقة والسياسات | صفحة **الشحن والاسترجاع** الجديدة + قائمة سياسات في صفحة المنتج بروابط فعلية + نشرة بريدية بالتذييل |
| 🟡 SEO | عنوان ووصف فريدان لكل صفحة (`usePageTitle`) + بيانات JSON-LD منظمة للمنتج |
| 🟡 إمكانية الوصول | تباين أقوى للنصوص الثانوية + `prefers-reduced-motion` + alt لكل صورة + aria-labels |

**نتيجة التقييم البصري VLM:** قبل 4.5/10 ← بعد **8.5/10 (كمبيوتر) / 9/10 (صفحة المنتج جوال)**

## 🚀 جاهزية الإطلاق التجاري (جديد في v1.1.0)

تنفيذاً لتوصيات تقرير فحص الجاهزية، أُغلقت كل المانعات الحرجة (P0) وأهم فجوات P1:

| الفجوة (من التقرير) | الحل المنفّذ |
|---------------------|--------------|
| 🔴 ثغرة `/api/auth/token/` بلا تحديد معدل | `ThrottledObtainAuthToken` بنطاق `auth` المشدد (10/دقيقة) + اختبار يثبت الإغلاق (429) |
| 🔴 لا استعادة كلمة مرور | مسار كامل: طلب البريد (بلا تعداد مستخدمين) → رابط أحادي الاستخدام 24 ساعة → إبطال كل الجلسات + صفحتا واجهة |
| 🔴 لا بنية بريد | إعداد SMTP عبر `.env` (console للتطوير) — جاهز لربط مزود حقيقي |
| 🔴 لا بوابة دفع | بوابة موحّدة: **Moyasar** حقيقي (جيب/Visa/MC) + وضع **محاكاة** للقبول والتدريب — تدفق كامل بتحقق خلفي |
| 🔴 لا امتثال ZATCA | فاتورة إلكترونية مبسطة (المرحلة الأولى): QR بترميز **TLV Base64** (البائع/الرقم الضريبي/الطابع/الإجمالي/الضريبة) + `GET /api/orders/{id}/invoice/` + عرض وطباعة من الواجهة |
| 🔴 صفحات قانونية mailto وهمية | صفحات حقيقية: الشروط، الخصوصية، الأسئلة الشائعة، اتصل بنا — بروابط فعلية وبيانات من `/api/config/` |
| 🔴 شعارات دفع مضللة في التذييل | الشعارات تظهر فقط عند التفعيل الفعلي + شارة واضحة «بوابة معاينة تجريبية» في وضع المحاكاة |
| 🟡 لا توثيق API | **Swagger/OpenAPI 3** عبر drf-spectacular: `/api/docs/` + `/api/schema/` |
| 🟡 إعدادات الواجهة مكتوبة يدوياً | `GET /api/config/` عام بلا أسرار: وسائل الدفع المفعلة + بيانات الدعم + الضريبة |
| 🟡 SEO أساسي | وصف meta + Open Graph + robots.txt |

**نقطة تحقق ذهبية:** دفع بالبطاقة (محاكاة) → تأكيد فوري → فاتورة ZATCA بـ QR — رحلة كاملة مُختبرة آلياً وبالمتصفح.

- ✅ ترقيم طلبات احترافي متين `TRZ-YYYYMMDD-XXXXXX` (عشوائي مقاوم لسباق التنفيذ)
- ✅ إحصائيات لوحة تحكم جاهزة (مبيعات 30 يوماً باستعلام واحد، أفضل المنتجات، أحدث الطلبات، الإيراد المحصّل)
- ✅ حذف منطقي للمنتجات المرتبطة بطلبات
- ✅ حدود طلبات (Throttling) + حد مشدد للمصادقة + سجلات + إعدادات بيئة عبر `.env`
- ✅ **113 اختبار API** شامل (مصادقة، صلاحيات، مخزون، دورة طلب كاملة، **+ اختبارات أمنية لكل ثغرة أعلاه**)

## 🚀 البدء السريع (تطوير محلي)

### 1. الخادم الخلفي
```bash
cd taraz_backend
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # الإعدادات الافتراضية للتطوير

python manage.py migrate
python manage.py seed_data      # بيانات تجريبية واقعية + حسابات جاهزة (التطوير فقط)
python manage.py runserver
# → http://localhost:8000/api/health/
```

### 2. المتجر الإلكتروني
```bash
cd taraz_marketplace
npm install
npm run dev
# → http://localhost:5173
```

### 3. لوحة الإدارة
```bash
cd taraz_desktop
npm install
npm run dev
# → http://localhost:3000
```

> الواجهتان تتصلان تلقائياً بالخادم عبر Vite proxy — لا إعداد إضافي مطلوب.
